Prompt Studio H3 Motion Context (PSV_H3MotionContext) takes conditioning, latent, video_vae, audio_vae, context_latent_path, context_video and context_frames. It outputs conditioning, latent and trim_frames. Place it after Director conditioning/latent creation and before the guider/sampler. It transfers a prior segment's video/audio tail into the new target with native Soft AV masks. Use the supported continuation recipe; the widget range does not mean arbitrary overlap lengths or batch sizes are supported. Missing or incompatible context must be resolved, not replaced by a guessed path.
Prompt Studio Save H3 Context (PSV_H3SaveContext) takes the sampled LATENT, project_id, generation_id and context_frames, writes a compact video/audio latent tail, and returns STRING context_path. It is an output node for continuation state, not a rendered video saver. Keep native SaveVideo for the actual clip. Project/generation identifiers associate the tail with its source.
Prompt Studio Trim H3 Context (PSV_H3TrimContext) takes decoded IMAGE images, AUDIO audio, trim_frames and fps. Connect Motion Context's trim_frames. Outputs images/audio are the new segment with the repeated head removed; assembly_images/assembly_audio retain the overlap for cumulative assembly. Trimming keeps audio and video aligned. Do not concatenate both overlap-bearing segments unchanged or trim the same head twice.
Video Studio's continuation flow inserts the required context wiring in its queued snapshot and keeps source/child lineage. Prefer that flow for extensions; do not manually edit saved generations or treat a context file as a Director media image. Use video-stages help for the distinction between shots, graph stages and successive renders.
