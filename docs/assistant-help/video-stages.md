For multiple shots in one production, use Add shot on the Timeline and edit each Shot Editor. Each shot's ordered steps contains action/dialogue; shots and their steps are document structure, not separate queued ComfyUI graphs. Reorder or adjust the timeline and review Prompt in the top bar before generation. Use one Director node for the whole document.
For multiple processing stages in one ComfyUI workflow, wire Director to the appropriate model/guider/sampler path, then matching video/audio decoding, CreateVideo and one native SaveVideo. Data links establish order, not canvas layout. Nested subgraphs must expose executable nodes; the template still requires exactly one executable Director and one native SaveVideo. Name stages clearly and add one Prompt Studio Input per supported scalar target to expose controls such as a stage's setting under Additional Inputs in the Shots inspector. Save [PSV], refresh workflows, select the workflow and verify the controls. Model/latent/conditioning connections remain typed graph wiring, not scalar custom inputs.
For a later continuation render, use Video Studio's extension flow on a completed source. It carries context forward, keeps the source immutable and creates a child segment with cumulative output. Context injection/trimming is handled by the continuation recipe. A structured extension retains its source workflow; its workflow selector is disabled and it uses Shot director instead of project Video director. An extension is not merely another shot added to the original render.
Saved-input replay uses the stored execution snapshot. Editing shots, workflow or custom inputs returns to current settings; it does not retroactively change the completed render. Do not promise an arbitrary automatic chain of independent workflows. If 'steps' is ambiguous, distinguish sampling iterations, shot action/dialogue steps and connected processing stages.
