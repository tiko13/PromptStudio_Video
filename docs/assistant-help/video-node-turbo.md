Prompt Studio MiniMax H3 Turbo Profile (PSV_MiniMaxH3TurboProfile) takes the Director's model, mode, width and height; preset, enabled and strength_model; and the four installed LoRA choices fl2va_mixed_8step_lora, fl2va_mixed_4step_lora, fl2va_768p_4step_lora and ref2va_4step_lora. It selects one acceleration LoRA for the resolved task and canvas. Keep the normal full-step workflow as a separate fallback and save Turbo wiring in its own [PSV] workflow.
Outputs: MODEL model, INT steps, FLOAT shift_video, FLOAT shift_audio, STRING profile and STRING lora_name. Wire model through any content LoRA chain and model patches into MiniMaxH3SigmaShift. Connect shift_video and shift_audio to that shift node, and steps to BasicScheduler.steps. The shifted model feeds both the guider and BasicScheduler. The selected LoRA and sampling settings are a coupled policy; changing a sampler's steps alone does not select a valid Turbo profile.
auto_quality chooses the dedicated 768p profile for its exact training canvas and the mixed quality profile for other base-mode canvases; fast_4step selects the mixed fast profile away from that canvas. REF2VA uses its own profile. Use the resolved profile outputs/current workflow for exact settings. Install the required LoRA files first; ambiguous basename matches require an exact relative path. Keep ordinary content LoRAs downstream, separate from acceleration routing.
Expose supported settings such as preset via Prompt Studio Input if needed. Disabling the node returns its non-Turbo fallback policy outputs; it does not recover arbitrary prior sampler settings. Do not claim unvalidated cache/acceleration combinations are supported.
