Video director discusses the whole project; the Shot director in a Shot Editor works on that shot. Review proposals before applying; discussion/help does not change the project.
The Director shares Prompt Studio's LLM backend and Keep models loaded. Leave that setting off when ComfyUI and the LLM share one GPU. Video generation releases the LLM first; the next Director request waits for rendering to finish and releases ComfyUI models. Managed Llama.cpp uses router model unloading and automatic loading while its server remains running.
With Keep models loaded enabled for separate GPUs, Video Studio preserves both the loaded ComfyUI models and the loaded LLM and skips shared-GPU handoffs. With Llama.cpp Start with ComfyUI also enabled, the shared backend loads its configured model at startup before any Director request.
Use Add shot on the Timeline for another shot; drag shots to reorder or resize their boundaries. Double-click a shot for its local cue timeline; timeline controls select roll/ripple and event-resize policy. Prompt in the top bar previews the compiled generation prompt. The structured document remains authoritative. Structured extensions use the per-shot Director; the project Video director is unavailable there.
For speech spanning a cut, give the adjacent dialogue segments the same Dialogue link ID while keeping speaker, language and performance consistent. Put only the exact segment's spoken words in each shot. Prompt shows advisory checks for rushed speech and conflicting camera movement; these never rewrite your text.
Prompt > Review specialist rewrite compares pasted LightX2V enhanced_prompt JSON or text against the current structured prompt. Choose 8B for base modes or Omni for reference mode. Use as Director draft opens a reviewable conversion request; send it and review the proposal before applying. The rewriter itself must be hosted separately. Checks do not prove visual quality or authorize changes to protected dialogue, lyrics, IDs or visible text.
