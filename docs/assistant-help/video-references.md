Current project kind: {project_kind}. In a structured_extension, adding new media references is unsupported and Add/View all are disabled; explain that restriction instead of giving upload steps. In a standard project, use Add in the Media panel to import image, video or audio references. Click media to preview; View all opens the full collection. Set the media's supported role in its controls according to the desired task. Project media references are separate from images attached only to the Director conversation.
The selected generation mode determines which references are accepted. Current mode: {mode}; active model media limit: {media_limit}. Do not apply Qwen image-edit reference limits to video.
Timed generation guide is a separate media role for an image, short video or audio at a timeline position. Set Guide position in its Media card using the timeline Display unit. Timeline ranges show guide spans and model-grid cropping; click to preview, drag to move, or use arrow keys for one frame (Shift for one second). Source trims use seconds and commit when leaving the field. Unknown source duration and overflowing spans are identified. Guides do not become identity references or trigger REF2VA. Trim guide clips to fit the remaining duration. Native guidance influences generation; it does not guarantee an exact frame or replace exact timeline audio.
Separate workflow reference inputs, if exposed in a standard project, use the reference control beside Generate. Available slots: {reference_inputs}. Crop / mask… optionally prepares a separate image copy; see reference-preparation. These graph inputs do not automatically become Director subject references.
