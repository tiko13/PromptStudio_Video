Prompt Studio MiniMax H3 Director (PSV_MiniMaxH3Director) takes CLIP clip, VAE video_vae, VAE audio_vae and STRING document_json. Optional lazy MODEL inputs are fl2va_model and ref2va_model; the resolved mode requires the corresponding input. Only the active model branch is requested. The structured document is authoritative; use Director Canvas or Video Studio to edit it, rather than replacing it with compiled prose.
Outputs, in order: MODEL model, CONDITIONING positive, LATENT latent, INT frame_count, FLOAT effective_duration, STRING compiled_prompt, STRING mode, INT width, INT height. Auto resolves T2VA without references, I2VA with a first frame, FL2VA with first and last frames, L2VA with a last frame, or REF2VA for full references. This is a deterministic compiler/native conditioning node, not the conversational LLM Director.
Connect the selected model and positive conditioning to the native guider path, and latent to sampling. Decode video and audio using their matching VAEs; join them with native CreateVideo and save with SaveVideo. Use the resolved dimensions and timing outputs when another node needs them. Keep exactly one executable Director and one native SaveVideo in a compatible [PSV] workflow.
Video Studio injects the current document_json into a cloned workflow snapshot. Change shots, media and canvas through the document controls. Other scalar workflow settings can be exposed through Prompt Studio Input under Additional Inputs; do not use it to override document_json behind the editor. Multiple shots belong in one Director document, not separate Director nodes in the same Studio template.
